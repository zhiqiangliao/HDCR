# High-dimensional convex regression
This is the Python code for 'Variable selection in convex nonparametric least squares via structured Lasso paper' ([preprint available on arXiv](https://arxiv.org/abs/2409.01911)).

See `demo_slasso.py` and `demo_relax.py` for example.
